# Notifications Sevastopol

VK-бот для студентов и сотрудников СевГУ: оперативные оповещения о воздушных тревогах в Севастополе и новости университета в одном интерфейсе.

## Что умеет бот

- 🚨 **Статус тревоги** — текущее состояние воздушной тревоги в Севастополе
- 📰 **Новости СевГУ** — последние публикации с сайта университета (с защитой от повторной отправки)
- 📋 **Памятка** — инструкция по действиям при воздушной тревоге
- ⚙️ **Настройки** — управление уведомлениями, очистка истории новостей
- 🧪 **Тестовый режим** — проверка последних постов губернатора на наличие тревог
- **Автоматическая рассылка** тревог и новостей по расписанию (в разработке)

## Источники данных

| Источник | Что парсим | Метод |
|---|---|---|
| Михаил Развожаев (Губернатор) | Оповещения о тревогах | VK API `wall.get` (Сервисный ключ) + распознавание картинок-шаблонов |
| СевГУ | Новости университета | RSS (`sevsu.ru/novosti/rss.php?section=0`) |

> **Особенность парсинга губернатора:** Тревоги часто публикуются в виде картинок без текста. Бот распознает их по ID вложений (`PHOTO_ALERT_ID` и `PHOTO_CLEAR_ID`), а также по жесткому фильтру ключевых слов в тексте поста.

## Стек

- Python 3.11+
- `vk_api` — VK Bots LongPoll API и запросы к стене губернатора
- `feedparser` — парсинг RSS новостей СевГУ
- `apscheduler` — планировщик задач
- `SQLite` — хранилище подписчиков, истории оповещений и отправленных новостей

## Структура проекта

```text
Notif_Sev_bot/
```

## Установка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/Notif_Sev_bot.git
   cd Notif_Sev_bot
   ```

2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. **Настроить сообщество ВКонтакте:**
   - Включить «Сообщения сообщества» (Управление → Сообщения).
   - Создать токен сообщества (Управление → Работа с API → Ключи доступа) с правами на сообщения и управление.
   - Включить Long Poll API (Управление → Работа с API → Long Poll API) и отметить «Входящие сообщения».

4. **Получить Сервисный ключ (для парсинга губернатора):**
   - Перейти на [dev.vk.com](https://dev.vk.com) → «Мои приложения» → «Создать приложение» (тип Мини-приложение).
   - В настройках созданного приложения в подменю "Разработка" скопировать **Сервисный ключ доступа**.

5. Создать файл `.env` в корне проекта:
   ```env
   VK_TOKEN=vk1.a.ваш_токен_сообщества
   GROUP_ID=123456789
   BROADCAST_PEER_ID=2000000001
   VK_SERVICE_TOKEN=ваш_сервисный_ключ_приложения
   ```

6. Запустить:
   ```bash
   python bot.py
   ```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `VK_TOKEN` | ✅ | Токен сообщества ВКонтакте (для работы бота) |
| `GROUP_ID` | ✅ | Числовой ID сообщества (без минуса) |
| `VK_SERVICE_TOKEN` | ✅ | Сервисный ключ приложения (для чтения стены губернатора) |
| `BROADCAST_PEER_ID` | ➖ | ID беседы или пользователя для авто-рассылки |
| `CHECK_INTERVAL_MINUTES` | ➖ | Интервал проверки тревог (по умолчанию 2 мин) |

## Команды и кнопки бота

| Команда / Кнопка | Действие |
|---|---|
| `/start` | Регистрация и главное меню |
| `/test_alerts` или 🧪 Тест тревог | Проверка последних 30 постов губернатора на наличие тревог |
| 🚨 Статус тревоги | Показать текущее состояние (заглушка) |
| 📰 Новости | Показать новые новости СевГУ (которых нет в базе) |
| 🗑 Очистить новости | Сбросить историю отправленных новостей (в меню Настроек) |
| 📋 Памятка | Инструкция при ЧС |
| ⚙️ Настройки | Управление типами уведомлений |
