# Notifications Sevastopol

VK-бот для студентов и сотрудников СевГУ: оповещения о воздушных тревогах в Севастополе и новости университета в одном интерфейсе.

## Что умеет бот

- 🚨 **Статус тревоги** — текущее состояние воздушной тревоги в Севастополе
- 📰 **Новости СевГУ** — последние публикации с сайта университета
- 📋 **Памятка** — инструкция по действиям при воздушной тревоге
- ⚙️ **Настройки** — включение/отключение типов уведомлений
- Автоматическая рассылка тревог и новостей по расписанию

## Источники данных

| Источник | Что парсим | Метод |
|---|---|---|
| МЧС Севастополь | Оповещения о тревогах | RSS (`92.mchs.gov.ru/rss`) |
| СевГУ | Новости университета | RSS (`sevsu.ru/novosti/rss.php?section=0`) |

## Стек

- Python 3.11+
- `vk_api` — работа с VK Bots LongPoll API
- `feedparser` — парсинг RSS
- `apscheduler` — планировщик задач
- `SQLite` — хранилище подписчиков и истории оповещений

## Установка

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/Notif_Sev_bot.git
   cd Notif_Sev_bot
   ```

2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создать сообщество ВКонтакте и получить токен:
   - **Управление → Сообщения** → включить «Сообщения сообщества»
   - **Управление → Работа с API → Ключи доступа** → создать ключ с правами:
     - «Сообщения сообщества»
     - «Управление сообществом»
   - **Управление → Работа с API → Long Poll API** → включить, отметить «Входящие сообщения»

4. Создать файл `.env` в корне проекта:
   ```
   VK_TOKEN=vk1.a.ваш_токен_сообщества
   GROUP_ID=123456789
   BROADCAST_PEER_ID=2000000001
   ```

5. Запустить:
   ```bash
   python bot.py
   ```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `VK_TOKEN` | ✅ | Токен сообщества ВКонтакте |
| `GROUP_ID` | ✅ | Числовой ID сообщества (без минуса) |
| `BROADCAST_PEER_ID` | ➖ | ID беседы или пользователя для рассылки |
| `CHECK_INTERVAL_MINUTES` | ➖ | Интервал проверки тревог (по умолчанию 2 мин) |

## Команды бота

| Команда / Кнопка | Действие |
|---|---|
| `/start` | Регистрация и главное меню |
| 🚨 Статус тревоги | Показать текущее состояние |
| 📰 Новости | Последние 3 новости СевГУ |
| 📋 Памятка | Инструкция при ЧС |
| ⚙️ Настройки | Управление типами уведомлений |
